# PlayBeat Package

This folder contains a packaged copy of the PlayBeat project for distribution.

Files included:
- server.js
- products.json
- admin-inventory.html (lightweight placeholder)
- html_upload/admin-inventory.html (full copy placeholder)
- shared.js
- shared.css
- package.json

To run the backend:
1. Install Node.js
2. Run `npm install`
3. Run `npm start`
